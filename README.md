# 🗺️ Meu Roadmap de Estudos Dev

Este repositório é dedicado ao registro da minha evolução, anotações e exercícios práticos durante minha jornada no desenvolvimento **Full Stack**.

A ideia é acompanhar meu progresso desde os fundamentos do desenvolvimento Web até conceitos de **Back-end, DevOps, Cloud e Infraestrutura**.

---

## 🎯 Objetivo

Construir uma base sólida em desenvolvimento Full Stack por meio de estudos teóricos, projetos práticos e checkpoints de aprendizado.

O roadmap está dividido em três grandes áreas:

* 🎨 **Front-end**
* ⚙️ **Back-end**
* 🚀 **DevOps & Cloud**

---

## 📑 Roadmap de Estudos

### 🎨 1. Front-end Basics

Fundamentos necessários para criação de interfaces web modernas, responsivas e interativas.

* [x] **HTML, CSS & JavaScript** — Fundamentos da Web

  * 🚩 **Checkpoint:** *Static Webpages*

* [ ] **JavaScript Avançado & DOM** — Adicionando interatividade às páginas

  * 🚩 **Checkpoint:** *Interactivity*

* [ ] **npm, Git & GitHub** — Gerenciamento de pacotes e versionamento de código

  * 🚩 **Checkpoint:** *External Packages & Collaborative Work*

* [ ] **React.js & Tailwind CSS** — Componentização, reutilização e estilização de interfaces

  * 🚩 **Checkpoint:** *Frontend Apps*

---

### ⚙️ 2. Back-end Development

Desenvolvimento de APIs, integração com bancos de dados, regras de negócio e gerenciamento de usuários.

* [ ] **Node.js** — Execução de JavaScript no lado do servidor

  * 🚩 **Checkpoint:** *CLI Apps*

* [ ] **RESTful APIs & CRUD** — Criação de APIs, rotas e manipulação de dados

  * 🚩 **Checkpoint:** *Simple CRUD Apps*

* [ ] **PostgreSQL & Redis** — Persistência de dados e gerenciamento de cache

* [ ] **Autenticação com JWT** — Segurança de rotas e gerenciamento de usuários

  * 🚩 **Checkpoint:** *Complete App*

---

### 🚀 3. DevOps & AWS Infrastructure

Conhecimentos relacionados à implantação de aplicações, automação, monitoramento e infraestrutura em nuvem.

* [ ] **Linux Basics & Conceitos de DevOps** — Fundamentos de sistemas e infraestrutura

* [ ] **AWS Services** — EC2, VPC, Route53, SES e S3

  * 🚩 **Checkpoint:** *Deployment*

* [ ] **Monit & GitHub Actions** — Monitoramento, automação e CI/CD

  * 🚩 **Checkpoint:** *Monitoring & CI/CD*

* [ ] **Ansible & Terraform** — Automação e Infraestrutura como Código (IaC)

  * 🚩 **Checkpoint:** *Automation & Infrastructure*
